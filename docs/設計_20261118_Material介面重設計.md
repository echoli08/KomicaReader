# KomicaReader Material Design 3 介面重設計計畫

日期：2026-11-18
範圍：`app/src/main/res/**`（layouts、values、values-night、drawables、menus）與本計畫文件。**不修改任何 Kotlin / build 檔。**

---

## 1. 設計原則

1. **內容優先（content-first）**：文章與討論串是主角。介面用「暖色中性背景 + 純白（暖白）卡片 + 深琥珀品牌頂欄」三層結構，讓文字區塊自然浮出，不靠陰影堆疊。
2. **保留 Komica 品牌橘**：以琥珀橘（Amber/Orange）色系建立 Material 3 色調階層，不使用建議的紫色。品牌橘以兩種角色存在：
   - `kr_primary`：可讀的深琥珀（淺色模式為深橘棕，深色模式為亮琥珀），作為強調、連結跳轉標題、主要按鈕。
   - `kr_toolbar`：深琥珀棕的「品牌頂欄」表面（兩種模式皆為深色）。
3. **WCAG AA 對比**：正文 ≥4.5:1、次要文字 ≥3:1、圖形/圖示 ≥3:1。修正原設計的多處對比失敗（白字配 #FF9800、#9E9E9E 中繼資料、白字縮圖標籤等）。
4. **觸控與回饋**：所有可點擊元素 ≥48dp、間距 ≥8dp；卡片以 bounded RippleDrawable 提供按下回饋（state layer），不新增裝飾性動畫。
5. **一致性**：所有畫面同一套 Toolbar 樣式、同一套卡片樣式、同一套字級、同一套 4/8dp 間距、同一套深色模式行為。
6. **行為零變更**：所有 view ID、資源名稱、選單、FAB、滑動刷新、收合、最愛、引用預覽、圖片動作、Insets 處理（`WindowInsetsUtil`）全部保留。

### 既有程式碼對設計的硬限制（已核對 Kotlin）

| 限制 | 來源 | 設計對策 |
|---|---|---|
| `ApplyBrandStatusBar` 將狀態列設為 `kr_toolbar` 並強制白色圖示 | `WindowInsetsUtil.kt` | `kr_toolbar` 兩種模式皆為深琥珀棕，白圖示對比 ≥10:1 |
| `ScrollToPost` 以 `kr_surface_alt` 覆蓋 `itemView.background` 後還原 | `ThreadDetailActivity.kt` | 貼文卡維持 `android:background="@drawable/bg_card"`（LinearLayout 結構不換成 MaterialCardView，避免背景交換破壞卡片描邊/水波） |
| SwipeRefresh 以 `kr_primary` 著色 | Browse/ThreadDetail | `kr_primary` 兩種模式皆可作為 spinner 色 |
| FAB 圖示色由 XML `app:tint` 控制 | activity_thread_detail | 改為 `kr_on_fab`（對比 ≥3:1 於 FAB 容器色） |
| `previewCard` 由程式定位（寬 300dp） | ThreadDetailActivity | 維持 300dp 寬與 id/結構，僅改外觀 |
| 引用預覽、URL/引用 span 色使用 `kr_secondary` | PostAdapter | `kr_secondary` 定義為對比 ≥4.5:1 的連結色 |

## 2. 色彩系統（Material 3 語意角色 × Komica 琥珀品牌）

所有名稱維持不變（Kotlin 與版面引用安全），僅調整色值並新增 3 個 token：`kr_on_primary`、`kr_on_fab`、`kr_outline`。

| `kr_primary` | primary | `#B25E00` 深琥珀 | `#FFB554` 亮琥珀 | 淺色對 surface ≈4.6:1 ✓（引用預覽標題 13sp bold 可讀）；深色 ≈10:1 ✓ |
| `kr_on_primary`（新） | on-primary | `#FFFFFF` | `#3E2500` | 主要按鈕文字 ✓ |
| `kr_toolbar` | 品牌頂欄 surface | `#4A2C00` 深琥珀棕 | `#292013` | 白色標題/圖示/狀態列圖示 ≥10:1 ✓ |

## 3. 字體與字級（M3 Type Scale，系統 Roboto）

移除主題中冗餘的 `android:fontFamily`，採 M3 預設 Roboto 字階；版面以 `?attr/textAppearance*` 引用，深淺模式自動對齊。

| 角色 | 版面用法 | M3 對應 | 大小/字重 |
|---|---|---|---|
| 頂欄標題 | MaterialToolbar 預設 | titleLarge | 22sp / 400（M3 樣式自帶） |
| 卡片標題 | boardName、threadTitle、historyTitle、settingTitle、categoryTitle | titleMedium | 16sp / 500 |
| 內文 | threadPreview、postContent、messageText | bodyMedium / 15–16sp | 行距 1.5 |
| 次要說明 | boardDescription、settingDescription、historyUrl | bodySmall / bodyMedium | 12–14sp |
| 標籤/中繼 | boardPath、threadMeta、postHeader、settingValue | label 系 | 12–14sp / 500–bold |

貼文內文字級保留 Kotlin 傳入的 `postFontSizeSp` 動態大小（`postContent.textSize` 由程式設定，XML 僅提供 16sp 預設）。

## 4. 間距 / 圓角 / 高度

- **間距**：維持並沿用 4/8dp 節奏 token：`space_xs=4dp`、`space_sm=8dp`、`space_md=16dp`、`space_lg=24dp`。卡片內距統一 16dp（原 12dp），列表間距 8dp，RecyclerView 外距 16dp。
- **圓角**：`corner_card` 8dp → **12dp**（M3 medium shape），`bg_card`、`bg_thumb`、`bg_quote_preview` 共用此 token。
- **高度（elevation）**：卡片 0dp（以描邊 + 底色分層，flat/touch-first）；引用預覽浮層 8dp（功能性分離）；FAB 維持 Material 預設 6dp；頂欄 0dp。
- **觸控**：最愛星號 40×40 → **48×48dp**（borderless ripple）；FAB mini → `fabCustomSize=48dp`；圖片預覽工具列按鈕 40dp → **48dp**；表單 EditText `minHeight=48dp`；按鈕 `minHeight=48dp`；相鄰觸控間距 ≥8dp。

## 6. 各畫面規格

### 6.1 主畫面（activity_main / item_board / item_board_category）
- 深琥珀品牌頂欄（64dp + Insets 加高，維持 `ApplyToolbarInsets`），白標題「KomicaReader」＋三個白色選單圖示（主題切換/歷史/設定）。
- 暖紙灰背景；看板列為暖白卡片（12dp 圓角、描邊、bounded ripple）：名稱 titleMedium、描述 bodySmall muted、路徑 bodySmall 連結藍。
- 最愛星號 48dp borderless，`kr_warning` 色，contentDescription=「我的最愛」。
- 分類列：可點擊、borderless 按壓回饋；標題 titleMedium、收合狀態文案 bodySmall muted（文字由 Kotlin 產生，不變）。
- 載入中為置頂欄下的置中圓形進度（M3 以 `kr_primary` 著色）；空/錯誤狀態為置中 muted 文字（含「點擊重試」行為不變）。

### 6.2 討論串列表（activity_browse / item_thread）
- 同一頂欄樣式，標題由程式帶入看板名（不變）。
- SwipeRefreshLayout 保留，`setColorSchemeResources(kr_primary)` 生效（M3 色即可）。
- 執緒卡：76dp 縮圖（12dp 圓角暖底）＋標題 titleMedium（最多2行）＋預覽 bodySmall muted（3行）＋中繼 12sp bold `kr_thread_meta`；無圖時佔位字「文」改為深色 muted（修正原白字在淺底不可見），card 為可點擊 ripple。

### 6.3 討論串詳情（activity_thread_detail / item_post）
- 同一頂欄＋圖片牆/全部下載選單（新向量圖示，ID 不變）。
- 貼文卡：表頭 13sp bold `kr_post_header`、圖片 220dp `bg_thumb`、內文 16sp（字級由設定動態覆寫）。
- 引用預覽 `previewCard`：300dp、`bg_quote_preview`（surface + 琥珀描邊 + 12dp 圓角）、elevation 8dp；標題 `kr_primary`、內文 `kr_text`。程式定位邏輯不變。
- 三顆 48dp FAB（回覆/分享/到底部）：M3 primaryContainer（淺色 `#FFDDB5`+深棕圖示；深色亮琥珀+深棕圖示），間距 8dp，contentDescription 不變。

### 6.4 回覆（原生 activity_reply）
- 頂欄＋返回向量鍵；水平不確定進度條保留（M3 著色）。
- 表單欄位：M3 outlined 外框、48dp 高、16dp 欄距；送出＝filled primary（唯一主要動作）、選擇圖片＝outlined、使用網站回覆頁＝text button；狀態文字 muted。
- 所有 ID（nameEdit…browserButton）與行為（enabled 切換、imageText 顯示）不變。

### 6.5 網站回覆 / 驗證（activity_web_reply / activity_verification）
- 頂欄＋返回鍵；WebView 全域；驗證頁底部「我已完成驗證」＝filled primary 48dp；狀態列條 `kr_surface` 底 muted 文字。

### 6.6 設定（activity_settings / item_setting / item_board_category 節標）
- 同一頂欄＋返回鍵；節標＝titleMedium、列＝卡片（ripple）：標題 titleMedium、說明 bodySmall muted、值 labelLarge 連結藍（與左側間距 16dp）；列高 ≥72dp、可點擊。

### 6.7 歷史（activity_history / item_history）
- 同一頂欄（無返回鍵，維持原狀）；列＝卡片：標題 titleMedium、URL bodySmall 連結藍；點擊/長按刪除行為不變。

### 6.8 圖片牆（activity_image_grid / item_image_grid）
- 改用品牌頂欄（原為白底深字，與全 App 不一致），返回向量鍵，標題由程式帶入「圖片牆 (n)」。
- 3 欄格、8dp 外距/4dp 格距不變；縮圖以 `clipToOutline` 裁切 12dp 圓角，前景 ripple。

### 6.9 圖片預覽（activity_image_preview / item_image_preview）
- 沉浸式黑底、ViewPager/ZoomImageView 不變；計數膠囊白字；底部工具列三鍵改 48dp 白字膠囊 MaterialButton（輪播/下載/分享），標題切換（輪播↔暫停）由程式控制不變。
- 註：此畫面 Kotlin 未呼叫 `ApplyBrandStatusBar`，狀態列沿用主題的深琥珀色，屬既有行為，不另行變更。

## 8. 實作備註

- Kotlin 檔案：**0 個修改**。
- 版面僅更換樣式/顏色/尺寸屬性，不增刪互動節點；`previewCard`、`quickActionPanel`、`imageToolbar` 等程式操作容器結構不變。
- 新增檔案：`ic_arrow_back.xml`、`ic_image_wall.xml`、`ic_download_all.xml`；修改 `bg_card`（→RippleDrawable）、`bg_thumb`、`bg_quote_preview`。
- 消融：新增的 3 個色彩 token（`kr_on_primary`/`kr_on_fab`/`kr_outline`）分別對應 M3 必要的 on-primary、FAB 圖示、卡片描邊角色，皆有實際用途；其餘皆為既有資源改值。無新增多餘抽象或裝飾元件。
